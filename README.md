# Тема "UI тестирование с POM" — курс ЯндексПрактикум | Sprint_6

Для автоматизации тестирования был выбран сервис [ЯндексСамокат](https://qa-scooter.praktikum-services.ru/) — почасовая/посуточная аренда самокатов с возможностью доставки до метро.

В рамках подготовки к релизу создан чек-лист по функциональности:

## Основные сценарии проверки

### [Домашняя страница](tests/test_home_page.py)
- Успешный переход по кнопке **"Заказать"** в header на страницу оформления заказа
- Успешный переход по кнопке **"Заказать"** в разделе **"Как это работает"** на страницу оформления заказа
- При клике на логотип **"ЯндексСамокат"** происходит редирект на страницу **"ЯндексДзен"**

### [Вопросы о важном](tests/test_FAQ.py)
- При нажатии на вопрос раскрывается соответствующий ответ

### [Оформление заказа](tests/test_order_page.py)
- Успешное оформление заказа при использовании кнопок **"Заказать"**
- Правильное отображение заказа на странице **"Статус заказа"** с присвоенным номером
- Проверка валидации полей формы **"Для кого самокат"**:
  - Неверный формат Имени — отображается ошибка
  - Неверный формат Фамилии — отображается ошибка
  - Некорректный адрес — отображается ошибка
  - Неверное метро — отображается ошибка
  - Неверный номер телефона — отображается ошибка

## О репозитории

### Структура папок и файлов:
- В директории [`utils`](utils) размещены вспомогательные файлы:
  - `locators.py` — локаторы элементов
  - `test_data.py` — тестовые данные пользователя
  - `urls.py` — адреса страниц

- В директории [`pages`](pages) реализованы действия (Actions):
  - `base_page.py` — базовый класс страниц
  - `home_page.py` — действия на домашней странице
  - `order_page.py` — действия для страницы оформления заказа

## Установка и запуск тестов

Перед началом работы необходимо установить зависимости:

``` shell
pip3 install -r requirements.txt
```
Запустить все тесты из директории tests:
```shell
pytest tests --alluredir=allure_results
```
Посмотреть отчет в браузере:
``` shell
allure serve allure_results
```
